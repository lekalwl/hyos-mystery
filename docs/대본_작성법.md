# 그레이헤이븐 대본 작성법

편집기의 「태그 도움말」 탭과 같은 내용입니다. 태그 목록의 원본은 `src/engine/vocab.ts` 입니다.

## 한 줄 = 한 장면
```
// 주석 (화면에 안 나옴)
@배경 서재_밤 #암전전환        ← 무대 명령은 @로 시작
@음악 긴장
(#자막) 그레이헤이븐 저택, 밤 11시

(#기쁨)(#통통) 엘리: 대사      ← 표정·동작 태그 + 화자: 대사
(#놀람 #오른쪽에서 #오른쪽) 하워드: 대사
엘리[???]: 이름을 가린 대사
(#속마음) 엘리: 생각
(#화면밖) 하워드: 목소리만
해설은 화자 없이 그냥 씁니다.
(#칸) 만화칸 해설
(#암전칸) 검은 화면 위 만화칸
(#강조) 큰 글씨 한 줄
> 시간: 밤                     ← 콜론이 든 해설은 > 로 시작
```

## 의상 (스킨)
- 스프라이트 파일 이름: `캐이름_의상이름_감정이름.png` (예: `엘리_평상복_기쁨.png`). 편집기 「인물」 탭에 폴더째 끌어다 놓으면 인물·의상·표정이 한 번에 등록됩니다.
- 인물의 첫 번째 의상이 기본 의상. 에피소드 탭의 「시작 의상」으로 에피소드별 시작 의상을 정할 수 있습니다 (예: 1화는 평상복, 2화부터 인게임).
- 이야기 중 바꾸기: `@의상 모두 인게임` / `@의상 엘리 인게임` / 줄 태그 `(#인게임 #기쁨) 엘리: …`
- 바꾼 의상은 그 에피소드 안에서 계속 유지됩니다.

## 인물
- 처음 말하면 자동 등장(페이드인), 빈 자리(가운데→왼쪽→오른쪽…)에 섭니다.
- 표정·위치는 바꿀 때까지 유지, 동작은 그 줄에서 한 번.
- 표정 태그 = 인물 탭에 올린 표정 이름. 없는 표정은 임시 이미지 + 경고.

| 무대 명령 | 뜻 |
|---|---|
| `@배경 이름` (`#즉시` `#암전전환`) | 배경 바꾸기 |
| `@삽화 이름` / `@삽화 끝` | 화면 전체 일러스트 |
| `@아이템 이름` / `@아이템 끝` | 가운데 증거·아이템 |
| `@음악 이름` / `@음악 끝` | 배경음 (반복) |
| `@효과음 이름` | 다음 줄과 함께 한 번 |
| `@등장 인물 #표정 #위치` | 말없이 등장 |
| `@동작 인물 #표정 #동작` | 말하지 않는 인물 연출 |
| `@퇴장 인물` (`#왼쪽으로` `#오른쪽으로`) | 퇴장 |
| `@모두퇴장` | 전원 퇴장 |
| `@화면 #암전` / `#암전해제` / `#번쩍` | 화면 효과 |
| `@의상 인물(또는 모두) 의상이름` | 의상 바꾸기 |

| 동작 태그 | |
|---|---|
| 등장 · 왼쪽에서 · 오른쪽에서 · 불쑥 | 등장 방식 |
| 통통 · 깜짝 · 끄덕 · 도리도리 · 움찔 · 다가섬 | 한 번 |
| 떨림(바들바들) · 흔들흔들 · 숨참 | 대사 동안 계속 |

위치: 왼쪽끝 · 왼쪽 · 가운데 · 오른쪽 · 오른쪽끝
화면 효과(어느 줄에나): 번쩍 · 붉은번쩍 · 화면흔들림 · 암전 · 암전해제

## 스포일러 방지
갤러리·프로필은 독자가 이야기에서 **이미 본** 배경·삽화·아이템·스프라이트만 보여 줍니다. 인물 카드는 그 인물이 본명으로 말한 뒤에 열립니다 (인물 탭의 「처음부터 프로필에 공개」로 예외 지정). 운영자 브라우저에서는 모두 보입니다.

## 동작 · 자세

- 한 번 재생: `#빙글빙글 #한바퀴 #꾹 #쭉 #쿵 #펄쩍 #휘청 #부르르 #꾸벅 #돌진 #뒷걸음` (그리고 기존 `#통통 #깜짝 #끄덕 #도리도리 #움찔 #다가섬`)
- 대사 동안 반복: `#떨림 #흔들흔들 #헐떡 #둥실 #깡총 #계속회전`
- 자세(풀 때까지 유지): `#쓰러짐 #기절 #주저앉음 #웅크림 #갸웃 #기댐 #뒤돌아섬 #작아짐 #커짐 #흐릿 #실루엣` → `#원래대로`로 풀기

```
@동작 인물A #쓰러짐
(#놀람 #펄쩍) 인물B: 괜찮아?!
@동작 인물A #원래대로
```

## 카메라

```
@카메라 인물A          // 얼굴 쪽 1.8배
@카메라 70 30 2        // 가로 70%, 세로 30% 지점을 2배로
@카메라 전체 #천천히    // 다시 전체 (#빠르게 #즉시 #천천히)
```

## 조사

편집기 「조사」 탭에서 배경 위에 증거 칸을 그리고, 칸마다 대화를 씁니다. 대본에는 `@조사 이름` 한 줄. 필수 칸을 모두 보면 다음 줄로 넘어갑니다.

## 추가 동작 · 앞뒤 순서

- `#휙지나감`(왼쪽→오른쪽) / `#휙왼쪽`(오른쪽→왼쪽): 그 줄 동안 화면을 휙 가로질러 지나가고 사라짐
- 자세(유지): `#눌린상태` 살짝 눌린 채로, `#덜덜덜` 과장되게 계속 흔들림 → `#원래대로`로 풀기
- 겹칠 때 순서(유지): `#맨앞` / `#맨뒤` — 예: `@동작 인물A #맨앞`

## 대사 기록에서 이동하기 (독자 기능)

끝까지 읽은 에피소드는 목차의 「대사 기록」이나 재생 중 로그(L)에서 전체 대사를 볼 수 있고, 대사를 누른 뒤 「여기로 이동」으로 그 장면부터 다시 읽을 수 있습니다. 아직 다 읽지 않은 에피소드는 지금까지 읽은 곳까지만 보입니다.
