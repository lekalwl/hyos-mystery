# 연출 가이드 (작업자 메모)

연출 대본을 쓸 때 먼저 읽을 것. 9화(사이트 8화) 연출본과 사용자가 직접 고친 공개본을 비교해서 정리했다. 앞선 8화 분석(기계적 일괄 처리, 평평한 연기, 근거 없는 줌)도 포함한다.

## 작업 순서
1. 새 화를 받으면 **직전 화의 공개본(사용자 수정본)**을 먼저 읽는다. 사용자가 고친 곳이 곧 취향이다.
2. 배경·삽화·표정 목록을 확인하고, **원고에 쓰였지만 없는 자산**(투표·결과 삽화, 새 표정)은 작업 전에 한 줄로 알린다. 9화에서 사용자가 벤자민 투표·결과 삽화와 새 표정(고장, 뭐라고, 이놈봐라)을 직접 만들었다.
3. 장면을 읽으며 손으로 쓴다. 규칙을 일괄 적용하지 않는다.
4. 끝나면 편집기 미리보기와 같은 화면으로 대표 장면을 렌더링해서 눈으로 본다.

## 카메라 (9화에서 가장 크게 어긋난 부분)
- **줌은 더 가깝고 빠르게.** 내가 쓴 `1.7~1.8 #천천히`는 약하다. 사용자는 `2~3.3`배에 `#빠르게`나 즉시 컷으로 바꿨다.
- **인물 이름 대신 좌표를 써도 된다.** 얼굴 높이는 y 37~41, x는 자리 값(왼쪽끝 12, 왼쪽 28, 가운데 50, 오른쪽 72, 오른쪽끝 88) 근처다. 사용자가 쓴 예: `31 41 2`, `71 38 2`, `85 37 3.3`. 이전 지적은 **소품 위치를 모르면서 찍는 줌**이었지, 사람 얼굴을 당기는 줌이 아니다.
- **긴 대사는 중간에 끊어서** 말하는 사람 → 듣는 사람 반응 컷으로 넘긴다. 벤자민의 긴 추궁을 두 줄로 나누고 사이에 ■■ 반응 컷을 넣은 것이 예다.
- 천천히 당기는 카메라는 마지막 불길한 한 컷처럼 정말 느리게 보여 줄 때만 쓴다.
- 인물 카메라를 쓸 때 서술 패널(`(#칸)`)이 얼굴을 가린다. 그때는 평문 서술(하단 박스)을 쓴다.

## 표정
- **시리 계열은 극단일 때만.** 팡기르의 시리놀람·시리화냄, ■■의 시리비웃음은 대부분 놀람·화냄·비웃음·노려봄·음흉으로 바뀌었다.
- **평범한 대화는 `#일반`이 맞다.** 내가 ■■의 귀찮, 팡기르의 웃음, 벤자민의 눈감음·행복을 줄마다 갈아 끼운 곳이 `#일반`으로 되돌려졌다. 표정은 감정이 바뀌는 지점에서만 바꾼다.
- **듣는 사람도 연기하게 한다.** 사용자가 `@동작 골드쉽 #딴청`, `@동작 ■■ #짜증`, `@동작 벤자민 #뜨헉`처럼 대사 사이사이 반응 동작을 많이 넣었다. 내 대본은 듣는 사람이 몇 줄씩 같은 표정이었다.
- 원고에 적힌 행동은 동작 태그로 옮긴다. "주변을 둘러봤다"에 `#뒤돌아섬`/`#원래대로`, "고개를 기울였다"에 `#갸웃`이 그 예다.
- 로봇이라는 설정을 개그에 쓴다. 벤자민이 몰리면 `#고장`+`#떨림`, ■■이 "먹통이군."이라고 받는다. 내가 쓴 C-1000 `#챗지피티`는 `#쯧`으로 바뀌었다.

## 무대 · 배경 · 음악
- **토론·회의 장면은 전부 `토론장`.** 원고의 "경찰서 회의실"도 토론장으로, 자막은 "회의장"으로 바뀌었다. 아침 식사는 `식당` 대신 `여관`이었다.
- **투표 장면 음악:** 서스펜스가 아니라 `그레이븐헤이븐`. 대기실은 `일상`/`한가함`. `야뭐해`와 `추궁`은 적게 쓴다(10장 추궁은 `트릭설명`으로 바뀜).
- **몰리는 사람이나 핵심 인물은 가운데에 둔다.** 벤자민 추궁 장면에서 벤자민을 가운데, ■■을 오른쪽으로 옮기셨다.
- 시너·C-1000처럼 비중 있는 대사를 하는 사람은 `(#화면밖)`이 아니라 `@등장`으로 화면에 세운다. `(#화면밖)`은 정말 짧은 한마디나 등록되지 않은 사람에게만 쓴다.
- **4명 이상이면 말하는 사람 줄마다 `#맨앞`**을 붙인다(사용자 공개본 50회, 내 본 26회). 등장 줄에도 붙인다.
- 퇴장은 내가 넣은 것 중 일부가 지워졌다. 말이 길지 않은 사람 퇴장은 해야 하지만, 대사를 한마디 남긴 사람을 바로 퇴장시키는 식은 피한다.

## 서술
- **"X가 물었다/말했다/덧붙였다" 같은 말머리 서술은 쓰지 않는다.** 원고에 있어도 화자가 화면에 있으면 사용자가 지운다.
- 긴 서술은 한 문장씩 `(#칸)`으로 나눈다.
- 회상 서술("며칠 전 장터에서…")에는 배경 전환+인물 등장으로 짧은 회상 컷을 만든다. 나는 정체를 감추려고 생략했는데, 사용자는 보여 주는 쪽이었다.

## 효과음
- **한 박자마다 한 번.** "한 번. 두 번."에는 `똑똑` 한 번이 아니라 줄마다 `SE_상자쿵`을 따로 넣으셨다. 문장 박자와 소리를 맞춘다.
- 서류·연필·도장 소리는 많이 써도 된다(공개본 8화 기준 100줄당 20회 안팎). 사소한 박수류만 뺀다.
- 책상 치기, 수첩 덮기 같은 큰 동작에는 `쿵`.

## 클라이맥스
- 탈락 장면은 **전용 삽화**(투표, 결과)와 **개그 비트**가 붙는 쪽이 사용자 취향이다. 대기실에서 라팜이 벤자민을 흔드는 장면은 `참교육` 삽화로 처리됐다.
- 몰린 사람은 비웃고 끝내지 않고 **로봇 고장 개그**로 한 번 꺾어 준다.
